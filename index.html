支持表情包专属分类、纯前端修改导出备注名（安全不改动仓库文件）、批量自定义格式导出外链
使用小贴士： 1. 安全导出改名：点击卡片「改名」仅修改用于展示与批量导出的备注名，不会变更 GitHub 仓库中的实际文件名，保证图片绝对不丢失、外链永久有效。
2. 表情包批量导出：勾选多个表情包后点击底部浮条的「批量导出」，支持自定义模板（如默认 {name}：{url}），一键生成所有外链列表并复制或下载。
3. 分类上传：可在上传区下拉菜单中选择分类，文件会自动归档在对应子目录下，手机与电脑端同步生效。
